# Expensify₹ — Personal Finance Tracker

A responsive personal finance tracker built with HTML, CSS and JavaScript.  
Expensify₹ helps users manage income and expenses, monitor their balance, analyze spending categories, and export transaction data.

## Live Demo

https://hemanth318-web.github.io/expense_tracker/

## Features

- User registration and login
- Add income and expenses
- Automatic balance calculation
- Monthly spending calculation
- Transaction history
- Edit transactions
- Delete transactions
- Search transactions
- Filter transactions by category
- Spending breakdown with interactive chart
- CSV transaction export
- Clear all transactions
- Form validation
- Responsive mobile-friendly interface
- Data persistence using browser localStorage
- Toast notifications and empty states

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Chart.js
- Font Awesome
- Google Fonts
- Browser localStorage
